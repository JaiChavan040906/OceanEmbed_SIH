# backend/data_assets/

Every data file the backend needs at runtime. Nothing is read from outside
the `backend/` tree — override any path in `backend/.env` if you keep the
file somewhere else.

| File | Size | Purpose |
|---|---|---|
| `stats.json` | 2 KB | Per-channel μ/σ used for standardisation |
| `static.npy` | 400 KB | Static channels `(4, 101, 241)` — land / lat / lon / bathy proxy |
| `climatology.nc` | 20 MB | Per-day-of-year SST mean + P90 for marine-heatwave detection (precomputed from train years) |
| `surface_2025.nc` | 125 MB | 8-channel daily satellite inputs for the test year |
| `target_2025.nc` | 145 MB | GLORYS `thetao` at 15 standard depths (ground truth for the test year) |
| `preds_v3.npz` | 625 MB | Cached model predictions for every day of the test year — produced by `evaluate_v3.ipynb` |
| `argo_test_2025.nc` | 386 MB | Quality-controlled ARGO float measurements for 2025 (~1.8 M points) — used by `/api/argo/*` and the confidence-score computation |

**Total: ~1.3 GB**

## Git LFS

Everything > 100 MB blows past GitHub's soft limit. This folder is tracked
via [Git LFS](https://git-lfs.com/). After cloning:

```bash
git lfs install
git lfs pull
```

The `.gitattributes` in `backend/` declares `data_assets/*.nc` and
`data_assets/*.npz` as LFS.

## Regenerating

- `climatology.nc` — one-time precompute from the training data:
  ```bash
  python scripts/precompute_climatology.py \
      --train-dir /path/to/harmonized/train \
      --out       data_assets/climatology.nc
  ```
- `preds_v3.npz` — regenerated by the evaluation notebook. Run the first four
  cells of `evaluate_v3.ipynb` and copy the result here.
- `surface_2025.nc`, `target_2025.nc`, `stats.json`, `static.npy` — produced
  by the standardisation scripts under `data/scripts/`.
- `argo_test_2025.nc` — see `data/scripts/download_argo_incois.py`.

## Overriding paths

If you keep any of these on a shared drive, set the corresponding variable in
`backend/.env` (e.g. `PREDS_CACHE=/mnt/share/preds_v3.npz`) and the backend
will pick it up. See `.env.example` for every knob.
